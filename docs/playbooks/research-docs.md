# Playbook: research & documentation

1. **find-docs** — current primary docs for any library/SDK/CLI question;
   never trust training data for API details.
2. **research** — high-trust primary-source investigation, findings captured
   as a Markdown file in the repo.
3. **domain-modeling** — record durable terminology (GLOSSARY.md / ADR).

Docs routing contract: OpenAI products → official OpenAI route; everything
else → Context7. See `skills/bak/references/documentation-routing.md`.
